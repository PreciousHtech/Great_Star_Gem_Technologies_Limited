# Custom Project Instructions & Guidelines

## Package Management
- **Primary Package Manager**: Always use `pnpm` instead of `npm`.
- Package installation commands: `pnpm add <package>`, `pnpm add -D <package>`
- Script execution: `pnpm run <script>` or `pnpm <script>`
- Dependency lockfile: Maintain `pnpm-lock.yaml`. Do not use `npm` or generate `package-lock.json`.
